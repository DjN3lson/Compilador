BENCHMARK
FAMILIA DE PROGRAMAS
------------------------------------------------------------------------------
  let v1 = 1 + 1 * 2;
  ...
  let vN = N + N * 2;
  mostrar(v1);
  ...
  mostrar(vN);

  Tamaño N = cantidad de declaraciones (y de mostrar).
  Todas las declaraciones van antes de los mostrar.
  Tamaños probados: [100, 1000, 5000]
  Repeticiones por tamaño y fase: 5

QUÉ INCLUYE CADA MEDICIÓN
------------------------------------------------------------------------------
  Compilación: subprocess que ejecuta
      py compilador.py familia_N.tc -o familia_N.salida.py
    Incluye:
      - arranque del intérprete Python,
      - lectura del archivo .tc,
      - lexer + parser + AST + análisis semántico,
      - generación de código y escritura del .py,
      - terminación del proceso.

  Ejecución: subprocess que ejecuta
      py familia_N.salida.py
    Incluye:
      - arranque del intérprete Python,
      - import del módulo automatas.py,
      - evaluación de expresiones y construcción
        de cadenas para print,
      - escritura de stdout (capturada por subprocess).

  No incluye:
      - generación de los archivos .tc (ya existen antes de medir),
      - compilación a bytecode de Python (puede ocurrir la primera vez).

==============================================================================

Fase: compilacion
  N=  100  mediana=  147.61 ms  (factor_n=  1.0, factor_t= 1.00)
  N= 1000  mediana=  190.61 ms  (factor_n= 10.0, factor_t= 1.29)
  N= 5000  mediana=  359.26 ms  (factor_n= 50.0, factor_t= 2.43)

  N=  100  mediana=   44.87 ms  (factor_n=  1.0, factor_t= 1.00)
  N= 1000  mediana=   57.16 ms  (factor_n= 10.0, factor_t= 1.27)
  N= 5000  mediana=  141.81 ms  (factor_n= 50.0, factor_t= 3.16)

Interpretación:
  - factor_t ≈ factor_n  -> escalamiento aproximadamente lineal.
  - factor_t < factor_n  -> overhead constante (arranque, I/O) domina.
  - factor_t > factor_n  -> componente superlineal a documentar.
==============================================================================
NOTAS PARA EL REPORTE
==============================================================================
  - La componente de arranque del intérprete Python (~30-50 ms) está
    incluida en cada medición. Por eso los N pequeños pagan un costo
    constante grande en proporción al trabajo real.
  - Para N grandes, el trabajo del compilador y del programa generado
    domina el arranque y el escalamiento tiende a lineal.
  - Estas mediciones apoyan el análisis asintótico del reporte, pero
    no lo demuestran por sí solas (Sección 7.3 del PDF).
